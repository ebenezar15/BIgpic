# Seated Together

A printable teaching app: the order of events from Eden to the new creation, read through six lenses
(postmillennial, partial preterist, union and the sons, life and immortality, heaven on earth, hopeful universalist).

Views: Timeline · Mind maps (Scripture web, Four Gospels & AD 70) · Already fulfilled · Reigning now · Six lenses · Teaching sheet.

Open `index.html` in a browser. Use the browser's Print command to print every view in order.
