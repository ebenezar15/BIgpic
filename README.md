# Seated Together

A teaching app on the reign of Christ and his body, read through six lenses
(postmillennial, partial preterist, union and the sons, life and immortality, heaven on earth, hopeful universalist).

Views: Home · Timeline · Mind maps · Already fulfilled · Evidence · Objections · Powers & mission · Reigning now · Six lenses · Teaching sheet (with quiz).

Tools: search everything (Ctrl/⌘ K or /), Teach mode (full-screen slides), theme switch, progress tracking.

Open `index.html` in a browser. Use the browser's Print command to print every view in order.
